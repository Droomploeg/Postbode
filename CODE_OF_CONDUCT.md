# Code of Conduct

This project follows the **Contributor Covenant, version 2.1**.

The full text is published at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — as a contributor, maintainer, or community member — you agree to abide by its terms.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it confidentially to:

**mark@droomploeg.nl**

All reports will be reviewed and investigated promptly and fairly. Project maintainers are obligated to respect the privacy and security of the reporter of any incident.

## Enforcement

Project maintainers are responsible for clarifying and enforcing the standards of the Contributor Covenant. They have the right and responsibility to remove, edit, or reject contributions that do not align with this Code of Conduct, and to temporarily or permanently ban any contributor for behaviors deemed inappropriate, threatening, offensive, or harmful.
